# Acme Robotics Model X200 — FAQ

*Knowledge base: Product Docs*

**Does the X200 work on carpet?**
Yes, low-to-medium pile. High-pile shag carpet isn't recommended — suction
performance drops significantly and it can affect navigation.

**Can it patrol and clean at the same time?**
No. Patrol mode and Clean mode are mutually exclusive on a given run; the
unit finishes one before starting the other, even if both are scheduled to
overlap.

**Is the camera recording all the time?**
Only during an active Patrol mode run. Clean mode does not use the camera
for recording, only for navigation obstacle-avoidance, and that footage
isn't stored.

**What's the difference between the X200 and X200 Pro?**
Same core hardware; the Pro has an extended battery and commercial-grade
filtration, and is sold to small offices and clinics rather than
direct-to-consumer. See `Model-X200-Manual.md` for the base unit's full
spec — Pro-specific documentation is out of scope for this knowledge base.

**My unit won't connect to Wi-Fi.**
Almost always a 5GHz network — the X200 only supports 2.4GHz. See the
troubleshooting table in `Model-X200-Manual.md`.

**Can I use it in a multi-story home?**
Yes, but each floor needs its own home-mapping pass; the unit does not
carry maps between floors automatically, and it cannot navigate stairs on
its own.

**Does it work with smart home platforms?**
Voice control via the Acme companion app's integration is supported for the
major platforms. This FAQ doesn't cover setup steps for each platform —
that's a separate integration guide outside this knowledge base's current
document set.

**How do I request a refund or report damage?**
That's a support-policy question, not a product question — see the Policy &
Refunds knowledge base (`Returns-Policy.md`, `Shipping-Damage-Claims.md`)
rather than this one.
